以下是读取并输出 JSON 文件的规范 Python 代码示例。代码中包含了异常处理以及针对中文字符的格式化输出处理。

```python
import json
from pathlib import Path


def read_and_print_json(file_path: str) -> dict | list | None:
    """读取 JSON 文件并美化输出内容

    :param file_path: JSON 文件路径
    :return: 解析后的 Python 对象（字典或列表），失败则返回 None
    """
    path = Path(file_path)

    # 检查文件是否存在
    if not path.exists():
        print(f"[Error] 文件不存在: {file_path}")
        return None

    try:
        # 打开并解析 JSON 文件
        with open(path, "r", encoding="utf-8") as file:
            data = json.load(file)

        # 格式化打印输出
        # indent=4 设置缩进，ensure_ascii=False 确保中文字符正常显示
        formatted_json = json.dumps(data, indent=4, ensure_ascii=False)
        print("--- JSON 文件内容 ---")
        print(formatted_json)

        return data

    except json.JSONDecodeError as e:
        print(f"[Error] JSON 格式解析失败: {e}")
    except Exception as e:
        print(f"[Error] 读取文件时发生未知错误: {e}")

    return None


# ================= 示例演示 =================
if __name__ == "__main__":
    # 1. 创建一个临时 JSON 文件用于演示
    demo_file = "demo_data.json"
    sample_data = {
        "project": "AI Assistant",
        "version": 1.0,
        "features": ["Code Generation", "Document Writing"],
        "status": {"active": True, "code": 200},
    }

    # 写入测试数据
    with open(demo_file, "w", encoding="utf-8") as f:
        json.dump(sample_data, f, indent=4, ensure_ascii=False)

    # 2. 调用函数读取并输出 JSON
    data = read_and_print_json(demo_file)

    # 3. 清理测试文件（可选）
    Path(demo_file).unlink(missing_ok=True)
```

### 关键技术点说明：
1. **`json.load(file)`**：直接从文件流中读取并解析 JSON 数据，转换为 Python 的 `dict` 或 `list`。
2. **`encoding="utf-8"`**：显式指定编码，防止在不同操作系统（如 Windows）下因默认编码问题导致中文乱码。
3. **`json.dumps(..., indent=4, ensure_ascii=False)`**：
   - `indent=4`：实现缩进排版，提高可读性。
   - `ensure_ascii=False`：禁止将非 ASCII 字符（如中文）转义为 `\uXXXX` 格式。
4. **异常处理**：捕获 `FileNotFoundError` 与 `JSONDecodeError`，保证工程代码的鲁棒性。
